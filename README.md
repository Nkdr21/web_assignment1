## 3. Final Reflection
This assignment was a highly valuable practical experience. Building the webpage step-by-step helped me solidify my understanding of how HTML provides the structure, while CSS brings the visual design to life. The most challenging but interesting parts were mastering the Box Model (understanding the difference between margin and padding) and managing layouts using Float and CSS Positioning. Seeing the final code successfully deployed and accessible via a live link gave me a great sense of accomplishment as a beginner in Front-End development.
