##  Objective
By completing this assignment, I practiced:
*   Understanding the structure and purpose of HTML.
*   Using basic and intermediate HTML tags to build a webpage.
*   Applying text formatting, images, links, lists, tables, and forms.
*   Understanding the role of CSS in web development.
*   Applying CSS properties to style colors, fonts, and backgrounds.
*   Creating structured layouts using the CSS box model, positioning, sizing units, and float/clear.
*   Publishing the finished webpage online using GitHub Pages.
